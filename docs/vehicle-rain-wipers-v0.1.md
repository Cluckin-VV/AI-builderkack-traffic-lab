# Vehicle rain wipers v0.1

## Scope

The three original Blender vehicle assets (sport sedan, urban SUV and low-floor
electric bus) now export two front-windscreen wiper blades and named pivot
centres.  The browser keeps those pivots inside each cloned vehicle instance.

This is a presentation-only detail.  The sweep reads the renderer's bounded
rain-weight transition and elapsed presentation time.  It does **not** read or
write a route, speed, signal phase, `SceneState`, preview result, Event Log, or
natural-language command.

## Rain behaviour

- Clear, snow and fog resolve to a resting angle.
- Rain uses a smooth, bounded +/-0.42 radian sweep.
- The effect is independent of vehicle motion: a stopped vehicle can keep its
  windscreen clear in rain, while wheel spray still requires both rain and
  actual movement.
- Wiper materials remain dark satin trim; no lens, headlamp, signal or glass
  material is changed by the effect.

## Reproducibility and budget

The editable `.blend`, `.glb` and runtime mesh JSON are generated by:

```powershell
& "output/tools/blender-4.5.9-windows-x64/blender.exe" --background --python tools/art/build_city_vehicles.py
& "output/tools/blender-4.5.9-windows-x64/blender.exe" --background --python tools/art/build_city_bus.py
```

The bus uses one un-bevelled blade per side plus explicit pivot metadata.  That
keeps the existing `bus JSON + textures < 10 MB` guardrail intact (observed
9,906,472 bytes on this build), rather than raising a loading budget just to
add near-camera decoration.

## Verification

- Node presentation tests cover bounded rain-only wiper state.
- Python visual-asset tests require two pivots and wiper geometry for sedan,
  SUV and bus.
- An isolated local Chrome check loaded the real WebGL assets, switched to the
  rain preview and recorded zero console warnings/errors.  The preview did not
  submit a domain command or Event Log entry.

This is an authored real-time scene cue, not a claim of scanned vehicles,
ray-traced rain droplets, GTA assets, DLSS, or a physical vehicle simulation.
