状态：**待真实非开发者测试**  
测试对象：AI Builder 本地 Canvas 透视 3D 交通场景  
测试目标：验证陌生用户能否自然表达交通场景变化，而不依赖开发者解释。

## 测试前提

1. 启动服务：`python -m ai_builder.server`
2. 打开：`http://127.0.0.1:8000`
3. 测试者只看页面，不阅读代码。
4. 每条指令单独记录原始输入、页面显示的 `accepted/rejected`、场景变化和 Event Log。
5. 测试者可以提问，但记录其是否需要解释；测试过程中不得提前告诉固定指令协议。

### 已知待验证的自然表达

至少需要确认以下两类表达是否能被当前协议理解：

- “再增加一辆公交车”——可能表达已有动作的重复执行；
- “把信号灯恢复绿色”——可能表达现有 `set_traffic_light` 动作的另一种自然语言形式。

以上只是测试假设，不是测试结论。

## 决策规则

- 如果 6 条中有 5 条以上被陌生用户自然理解，且失败项集中在少数明确动作：先扩充命令协议和确定性编译规则。
- 如果用户大量使用开放式表达，且同一意图出现多种说法，导致确定性规则快速膨胀：再评估让 LLM 只生成候选 `SceneAction`；LLM 不得直接修改 `SceneState`。
- 在真实测试结果填写前：**不接入真实 LLM，不扩充动作，不改变 Validator 边界**。
